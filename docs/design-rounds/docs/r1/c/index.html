1c   Docs, layout rung 1, Lane C: "reader first"

Thesis: the docs page is one reading column. Navigation stays one control away: the page tree lives in a drawer on every viewport; a docs bar carries the drawer button, a breadcrumb and a search field that never leaves the screen; the page's own table of contents is a strip under its title. Named axis: what is dominant (the page being read, not the tree around it).

Worse at: browsing. The reader never sees the page tree beside the page, so "what else is in this section" costs a click on desktop as on the phone; siblings are found by drawer, by prev and next, or by search, not by glancing left. At 1440 about half the width is empty margin. The sidebar highlight that J3.3 and J1.5 name exists only inside the open drawer; the breadcrumb carries "where am I" instead.
