01 Getting started

Run it

README.md, “Run it” · differential-attestation@9b4243d

Clone DA with its pinned checker, run it on one pull request, then run the regression table and the benchmark.

#Requirements

toolversionrunswithout it
node24lean, every command on this pagenothing runs
python33the proof lane (lane A); the benchmark scriptslane A answers ASK
dafny4the proof lane (lane A)lane A answers ASK
Note

Lane B needs only Node 24. Without Python 3 and Dafny 4 every command still runs; lean answers ASK on the proof lane.

#Clone

The checker is a submodule, pinned to the admitted lean master.

bash
git clone https://github.com/NexusGPT/differential-attestation && cd differential-attestation
git submodule update --init lean            # the checker, pinned to the admitted lean master

#Check one pull request

Every changed function and its callers, one table. --scope names the functions the change was meant to touch.

bash
node lean/langs/ts/pr.mjs --repo <checkout> --base <base sha> --head <head sha> --scope <function,Class.method>

Replay the immich example

Check out immich-app/immich, a public pull request from AACR-Bench (#17879), and run it from the merge base to the head.

bash
node lean/langs/ts/pr.mjs --repo <immich checkout> --base d0014bdf --head b7a12558
output
d0014bdf → b7a12558
5 changed function(s): 4 WITNESS · 0 PASS-proved · 1 PASS-bounded · 0 ASK
filefunctionverdictnote
server/src/services/notification.service.tsNotificationService.handleAlbumUpdateWITNESSinput 6: outcome; notification.service.ts:343

The certificate behind the row names the input it drew and the two lines where the versions part.

certificate
input   { id: "-1", recipientID: "vdiyf", notify: true, force: true, delay: 1, source: "copy" }
parent  notification.service.ts:324   recipientIds.includes(user.id)
cand.   notification.service.ts:343   return JobStatus.SUCCESS;
Note

A newer lean can word a line differently. The verdict and the input are what the certificate fixes. The committed report: baseline/immich-app__immich-17879.md.

#Read the verdict

PASS
Only the asked change.
REFUSE
The location, the input or the artifact, both outcomes, the lines.
ASK
What could not be decided, by name.

Per function, lean answers WITNESS (an input on which the versions part), PASS-proved, PASS-decided, PASS-bounded (how far it looked, never a proof) or ASK. Verdicts, in full →

#The regression table

A lean head reaches lean's master only with every row at or above its floor. A floor moves only with a written reason.

bash
# rows R1 to R11 against their floors
harness/regress.sh "$PWD/lean"

#The benchmark

Run, then score. The recount rebuilds the AACR-Bench table from the committed records, with no model call.

bash
python3 -I benchmark/run.py --lean lean --manifest benchmark/manifests/lane2-clean.v1.json --slice 20 --jobs 4
python3 -I benchmark/score.py --manifest benchmark/manifests/lane2-clean.v1.json --results <run dir> --require-eligible

# recount the AACR-Bench table (no model call)
python3 research/open-code-review/d3/harness/tables.py <floor dir> <composed dir> <floor judge.jsonl> <composed judge.jsonl> --out tables.json
