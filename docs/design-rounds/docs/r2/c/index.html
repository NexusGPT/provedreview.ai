Seven entry points. All exit 0 on any verdict and 2 with none.

1Commands

CommandScope
check.mjsone function, two versions
pr.mjsevery changed function of a pull request
exec/run.mjsthe execution lane on its own
lint.mjswhat lean can and cannot reach in a file
ci/comment.mjsone pull request comment, updated on every push
bin/leanthe wrapper over the above
npm testthe conformance suite

FlagTakesIn the first run
--parentfile, before the change…/parent.ts
--candidatefile, after the change…/candidate.ts
--unitfunction nameapplyAll
--no-projectnoneset
--nnumber of generated inputs60
--seedinteger3
--outledger pathledger.json
ReplaySame --n and --seed on the same commit give the same ledger.
