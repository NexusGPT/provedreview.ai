Run it

srcNexusGPT/differential-attestation@9b4243dREADME.md § Run itpinned 2026-11-01

Clone differential attestation, pin lean, check one pull request. Node 24 runs the check; Python 3 and Dafny 4 add the proof lane.

#Requirements

toolversionused byif missing
node24lean, pr.mjsrequired
python33the proof lane, benchmark/*.pyproof lane answers ASK
dafny4the proof laneproof lane answers ASK
git—the lean submodulerequired

#Clone and pin lean

lean is a submodule, pinned to the lean master that passed the regression table.

#Check one pull request

pr.mjs checks every changed function in the range and its callers, and prints one table. --scope names the functions the change was meant to touch; every other function must come out equal.

Replay the AACR-Bench example: check out immich-app/immich and run pr.mjs on its pull request #17879.

filefunctionverdictnote
server/src/services/notification.service.tsNotificationService.handleAlbumUpdateWITNESSinput 6: outcome; notification.service.ts:343

##Read the verdict

PASS
Only the asked change.
REFUSE
The location, the input or the artifact, both outcomes, the lines.
ASK
What could not be decided, by name.
note

A newer lean can word a line differently. The verdict and the input are what the certificate fixes. The committed report: baseline/immich-app__immich-17879.md.

#Admit a lean head

A lean head reaches lean's master only with every row of the regression table at or above its floor. A floor moves only with a written reason.

#Run the benchmark

Run a slice of a lane, then score it. The recount rebuilds the AACR-Bench table from the committed judge logs, with no model call.
