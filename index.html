Use cases

Where a reader cannot keep up.

The gate reads neither the change text nor any statement by its producer. It runs both versions and compares them.

Core features

Three instruments. Five verdicts.

Each instrument compares two versions of the system and refuses on evidence. lean reports the strongest verdict the evidence supports.

RECORDINGinstrument 1

The system runs under a fixed stimulus set before and after the change. A difference outside the selected scope is refused.

The difference inside the scope must equal an edit the requester made on a real recording. 22 of 43 escaped defects caught, 4 of 43 clean changes refused.
PROOFPASS-proved · PASS-decided

lean proves the candidate equal to the parent for every input and every world. A component finite by its types is explored to the end.

statement: a loop with continue became a filter and a map. Equal_statement: true, 5 verified, 0 errors.
Toggle: PASS-decided, 8 state pairs over 2 assignment(s).
RELATIONinstrument 3

For every artifact that is not a function, a predicate declared outside the change compares the two versions.

Build and pipeline configuration, locale files, schemas, documents. With the artifact lane: 40 of 43 escaped defects caught.
VERDICTWITNESS

An input on which the two versions differ. lean draws it itself, and names the source line on each side.

applyAll: <= where the parent had <.
{"input":17,"floor":-1,"parent":1,"candidate":0}
VERDICTPASS-bounded · ASK

No difference found within a stated bound, and it says so. A bounded pass never becomes a proof. ASK names the construct.

Quick start

One function, one verdict.

Lane B needs only Node 24. Python 3 and Dafny 4 run the proof lane; without them lane A reports ASK.

01

Clone

The checkout holds the pairs the runs below use.

$ git clone https://github.com/NexusGPT/lean && cd lean
02

Check one function

Parent, candidate, unit name. lean picks the lanes and draws the input.

$ node langs/ts/check.mjs --parent langs/ts/tests/pairs/readme_ledger/parent.ts --candidate langs/ts/tests/pairs/readme_ledger/candidate.ts --unit applyAll --no-project --n 60 --seed 3 --out ledger.json
$ jq -c '.witness | {input, floor: .args[3], parent: .parent.outcome.returned.posted, candidate: .candidate.outcome.returned.posted}' ledger.json
{"input":17,"floor":-1,"parent":1,"candidate":0}
