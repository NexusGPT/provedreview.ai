The method

Three instruments. Zero trust in the author.

Differential attestation reads neither the change text nor any statement by its producer. Each instrument compares two versions of the system and refuses on evidence.

01

Recording

The system runs under a fixed stimulus set before and after the change. Any difference outside the scope the requester selected is refused. The difference inside it must equal an edit the requester made on a real recording.

22 of 43 defects
02

Proof

For every function outside the scope, lean proves the candidate equal to the parent, or returns an input on which they differ. A proof is checked by Dafny; a witness is a run you can replay.

31 of 43 with the proof lane
03

Relation

For every artifact that is not a function: build and pipeline configuration, locale files, schemas, documents. A predicate derived from an authoritative artifact, or declared outside the change, compares the two versions.

the artifact lane
lean

Five words. Each one earned.

lean is a differential equivalence checker for TypeScript. Two versions of a function in, one verdict out, with the evidence that backs it.

PASS-proved

A theorem, checked.

Lane A translates both versions to Dafny and proves them equal for every input and every world. The certificate names the theorem and the prover version.

PASS-decided

A state space, exhausted.

A component is explored over every click order from every prop assignment. As final as a proof for that component.

WITNESS

An input that differs.

Lane B runs both versions in a sandbox with a frozen world and draws inputs, the special numbers included. The witness names the source line on each side.

PASS-bounded

No difference found, and it says so.

A bounded run keeps its word: generated inputs, click sequences to a stated depth, seconds per lane recorded in the certificate.

ASK

Refuses to guess.

A loop with no measure, a result that may share an input, a value whose type nothing checked. lean names the construct and the rewrite, in the editor, before the change ships.

The row

Screens, too.

Two builds rendered on the same screens under one pinned browser: pixels, layout boxes and the accessibility tree, with every tolerance in a parameters file. No model anywhere.

Quick start

One function. Three minutes.

node 24 for lane B. python3 and Dafny 4 for the proof lane, or the container image with both pinned.

01

Install

Clone the checkout, or build the image with node, Dafny and Z3 pinned.

$ git clone https://github.com/NexusGPT/lean && cd lean
$ docker build -t lean:local .
02

Check one function

Two versions of a file, one unit name. lean picks the lanes.

$ node langs/ts/check.mjs --parent old.ts --candidate new.ts --unit applyAll --no-project --n 60 --out ledger.json
WITNESS -> ledger.json
03

Read the certificate

One JSON per function: the verdict, what backs it, the hashes of both sides, the seconds each lane took.

$ jq -c '.witness | {input, parent: .parent.outcome, candidate: .candidate.outcome}' ledger.json
{"input":17,"parent":{"returned":1},"candidate":{"returned":0}}
